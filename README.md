# Tools

A collection of daily life useful tools for automation.

## Projects

- **auto-brightness** – Automatic brightness adjustment tool.
- **file-search** – Fast file search utility.
- **ultra-fast-bulk-file-renamer** – Bulk file renamer for large sets of files.
- **ultra-fast-duplicate-finder** – Quickly find duplicate files.
- **youtube-downloader** – Download YouTube videos.

## Usage

Each project is contained in its own directory. Navigate to the specific folder and follow the instructions in its respective README or source files.
